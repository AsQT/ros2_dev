# calibrationdata

Camera calibration data storage for this workspace. Contains calibration files (e.g., `ost.txt`, `astracam_info.yaml`) generated by the ROS 2 camera calibration tool.

## Structure

```
calibrationdata/
├── astracam_info.yaml        # (unused / reference)
├── left-XXXX.png             # Calibration checkerboard images (left camera)
├── ost.txt                   # Output stereo calibration file
└── README_old.md            # Previous documentation
```

## Calibrate a Camera

Use the `camera_calibration` package from `image_pipeline`:

```bash
# Example: Calibrate a USB webcam
ros2 run usb_cam usb_cam_node_exe \
  --ros-args \
  -r __ns:=/webcam \
  -p video_device:=/dev/video2 \
  -p image_width:=640 \
  -p image_height:=480 \
  -p pixel_format:=yuyv \
  -p framerate:=30.0 \
  -p camera_name:=webcam

# Run calibration
ros2 run camera_calibration cameracalibrator \
  --size 7x5 \
  --square 0.029 \
  --no-service-check \
  --ros-args \
  -r image:=/webcam/image_raw \
  -r camera:=/webcam
```

After calibration, data is saved to `/tmp/calibrationdata.tar.gz`.

## Save Calibration Files

```bash
# Copy and extract
cp /tmp/calibrationdata.tar.gz ~/ros2/calibration/<camera_name>/
cd ~/ros2/calibration/<camera_name>/
tar -xzf calibrationdata.tar.gz

# Rename to standard format
mv ost.yaml <camera_name>.yaml

# Install to ROS camera_info store
mkdir -p ~/.ros/camera_info
cp ~/ros2/calibration/<camera_name>/<camera_name>.yaml ~/.ros/camera_info/
```

## Notes

- `left-XXXX.png` images are checkerboard captures from the calibration process.
- `ost.txt` contains the old stereo calibration output (OST version 5.0 format).
- Calibration intrinsics (K, D, R, P) are embedded in YAML files compatible with ROS 2 camera info publishers.
