# Huong dan chay Mock Hardware + DRL (Khong dung Gazebo)

## Gioi thieu

Stack nay chay DRL planning + MoveIt + RViz chi voi mock_hardware, khong can Gazebo.

## Cac thanh phan

1. `robot_state_publisher` — publish robot model tu xacro
2. `ros2_control_node` — mock hardware (GenericSystem)
3. `MoveIt move_group` — motion planning
4. `Task executor` — service `/move_cartesian_pose_sequence`
5. `DRL planner` — DRL inference + trajectory visualization
6. `RViz` — hien thi robot model va trajectory

## Hieu chinh

1. Build:
```bash
cd ~/ros2
colcon build --packages-select robot_drl robot_description robot_control
source install/setup.bash
```

2. Chay:
```bash
# Planning + RViz (mac dinh)
ros2 launch robot_drl drl_mock_hw.launch.py

# Auto-plan on startup (khong can nhap tay)
ros2 launch robot_drl drl_mock_hw.launch.py \
    auto_plan_on_start:=true \
    manual_prompt_on_start:=false

# Custom target position
ros2 launch robot_drl drl_mock_hw.launch.py \
    auto_plan_on_start:=true \
    manual_prompt_on_start:=false \
    target_x:=0.575 target_y:=0.050 target_z:=0.120
```

## Cac tham so

| Tham so | Mac dinh | Mo ta |
|---------|---------|-------|
| `auto_plan_on_start` | `true` | Tu dong plan khi bat dau |
| `manual_prompt_on_start` | `false` | Nhap target tu terminal khi bat dau |
| `auto_execute_after_plan` | `false` | Tu dong execute sau khi plan |
| `calibrated_start_tcp_base` | `[0.5241, 0.000, 0.315]` | Vi tri TCP ban dau (met) |
| `target_x/y/z` | 0.575/0.050/0.120 | Vi tri target trong world frame |
| `input_mode` | `manual` | Che do nhap: `manual` hoac `vision` |

## Ghi chu

- `auto_execute_after_plan:=true` chi hoat dong voi Gazebo (drl_test.launch.py). Mock hardware hien tai chi ho tro planning + RViz visualization.
- Muon execute thuc su voi robot, dung `drl_test.launch.py` (co Gazebo).
